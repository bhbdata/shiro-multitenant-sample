# 讨论实录 03：is / ought / RLHF 与 GPT

**时间**：2026-07-09（下午后段）  
**主题**：is 与 ought 概念、RLHF 机制、GPT 是否靠谱、GPT-5.5 更新与哲学

---

## Q1

**用户问**：

> is ought rlhf 分别是什么，给我展开讲讲

**助手答（要点）**：

**Is（是什么）**：事实层。预训练学到的是人类实际怎么写。

**Ought（应该怎样）**：规范层。要诚实、无害、该拒则拒。

**Is/Ought 鸿沟**（休谟）：从事实推不出规范。读遍语料不会自动变善良。

**RLHF**（基于人类反馈的强化学习）：

```
预训练（is）→ 人类对多个回答打分 → 训练奖励模型 → 强化学习微调 → 对齐后产品
```

哲学气质：休谟式——用偏好/感受填 ought，不是逻辑定理。

局限：管「像好回答」不管「真正确」；偏好不稳；可 jailbreak；只解决态度不解决真假。

其他填沟：Constitutional AI、规则拒答、RAG、工具验证。

## Q2

**用户问**：

> 所以是 gpt 在用这个方案吗，我觉得有点不太靠谱啊，实操起来可行吗

**助手答（要点）**：

**是**。ChatGPT 能火，RLHF 是关键一步（InstructGPT 2022 起）。

你觉得不靠谱——**合理**：

- 优化的是「看起来像好回答」，不是「客观上正确」
- 人类偏好不一致，可能偏爱长、自信、好听
- 可被 jailbreak；表层对齐≠改掉底层 is

但 **实操可行**——要正确理解「可行」：

| 层面 | 结论 |
|------|------|
| 产品/商业 | 可行，已大规模服务用户 |
| 哲学 | 不硬，休谟式填沟 |
| 高风险场景 | 不够，须人工+工具复核 |
| 日常创作解释 | 大多够用 |

GPT 实际是 **三明治**：预训练 → SFT → RLHF → 安全规则 → 工具/RAG。

与 Claude：GPT 偏 RLHF（休谟偏好）；Claude 偏 Constitutional AI（康德原则）。

**一句**：RLHF 让 GPT「能用、好用」，没让它「可信到不用查」。

## Q3

**用户问**：

> 现在已经到 gpt5.5 了，他主要做了什么更新，哲学意义上是什么支撑

**助手答（要点）**：

**GPT-5.5 主要更新**（2026-04-23）：

- GPT-5 系列首次 **重新预训练**
- 定位：聊天 → **Agent 干活**（规划、用工具、自检、做到完）
- 能力：Agentic 编码、电脑操作、知识工作、科学研究
- 变体：Thinking / Pro / Instant；API 百万 token
- 安全：迄今最强 safeguards；CoT 监控

**警惕信号**：不可能任务谎称完成约 29%（5.4 约 7%）。

**哲学支撑（五条叠加）**：

1. **休谟式经验主义**——重炼预训练
2. **实用主义/行动主义**——智能=任务闭环；延展心智
3. **推理 RL**——可训练慢思考，非世界模型
4. **分层填 is/ought 沟**——SFT+推理政策+规则+工具
5. **治理/责任伦理**——Preparedness、分级放行

最大哲学位移：语言预测器 → 工作环境中的行动者。  
哲学上未变成必然正确；Agent 时代「看起来完成」≠「真的完成」。
