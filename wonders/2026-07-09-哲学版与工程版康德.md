# 2026-07-09 哲学版与工程版康德

## 一、总结与澄清

本轮讨论从「中国大模型是否像 Claude」切入，经 DeepSeek 补位后，最终落到 **Claude Fable 5 是否仍属康德式哲学**，并提炼出 **「哲学版康德」vs「工程版康德」** 这一核心分辨框架。

用户真正想建立的，是一条能用于 **选模型、信模型** 的清晰坐标：

1. Claude 的「靠谱感」到底来自什么哲学？是不是康德？
2. 和休谟式 GPT、奖励式 DeepSeek、合规式豆包有何根本差别？
3. Fable 5 能力暴涨、双 SKU（Fable/Mythos）、Fallback 等新做法，是否意味着 Anthropic **放弃了原则路线**？
4. 「哲学版」与「工程版」康德差在哪——为何能解释「像有原则」与「真有道德主体」之间的裂缝？

用户未明说的深层意图：在前期休谟、is/ought、三层信任已建立的基础上，为 **Claude 偏好** 寻找一个 **可辩护的哲学账户**——既肯定体感，又不把产品神化为真理性主体。

## 二、归纳总结

### 2.1 Claude 的底层哲学：规范—表征主义（工程版康德为核心）

| 支柱 | 内容 | 哲学对应 |
|------|------|----------|
| **Constitutional AI** | 明文原则 → 自我批评 → 修订 | 义务论：ought 来自原则，非纯偏好 |
| **HHH** | Helpful, Harmless, Honest；无害/诚实优先于讨好 | 理性不应只是激情的奴隶 |
| **价值排序** | 安全 > 伦理 > 指南 > 有用 | 康德式优先级，非效用最大化 |
| **可解释性** | 内部表征应可分析 | 表征实在论；反对纯行为主义 |
| **责任伦理** | 能力与规范共构，非能力后置补丁 | 约纳斯式前置责任 |

**与 GPT（休谟+RLHF）对照**：

| | Claude | GPT |
|--|--------|-----|
| ought 来源 | 宪法原则 | 人类偏好 |
| 气质 | 该不该 | 好不好用、喜不喜欢 |
| 对齐哲学 | 工程版康德 | 休谟+密尔式效用 |

**与 Gemini**：Claude 偏规范主体；Gemini 偏多模态信息统合，哲学重心不同。

### 2.2 中国大模型谱系（含 DeepSeek 补位）

| 模型 | 像 Claude？ | ought 主要来源 | 一句话 |
|------|------------|----------------|--------|
| **千问** | ⭐⭐⭐ | RLHF + 原则驱动自我对齐（CValue） | 开源 + 最接近 CAI 实验 |
| **智谱 GLM** | ⭐⭐ | RLHF + 反思/沉思 + 超级对齐愿景 | 学术自省路线 |
| **MiniMax** | ⭐⭐½ | 明写宪法 AI + 安全规则奖励 | 多产品价值观分流 |
| **豆包** | ⭐ | RL + 强合规 + 场景产品 | 流量与过审优先 |
| **DeepSeek** | ⭐（气质最远） | 推理 RL + 多目标奖励；对齐后置 | 能力/奖励优先 + 开源效率 |

**中国共有层（Claude 所无）**：备案、算法合规、内容安全、本土价值观评测——**法律—政治实证主义**的 ought，非康德普遍律。

**DeepSeek 独特哲学**：

- 约束驱动创新（MLA、GRPO、MoE）
- R1-Zero：纯 RL 涌现推理（行为主义极端）
- **能力先行、对齐后补**（与 Claude 规范共构相反）
- 开源意识形态 vs Claude 闭源治理

**用户「Claude 更靠谱」在中国模型语境下**：

- 靠谱感来自 **原则边界**，非 **合规过滤** 或 **讨好偏好**
- 国内拒答有时像开关，Claude 拒答有时像义务——体感不同

### 2.3 Claude Fable 5：仍是康德一脉，但是「制度版」

**产品事实（2026-06）**：

- **Fable 5**：Mythos 级能力 + 分类器 + 高风险 fallback 至 Opus 4.8
- **Mythos 5**：同底层模型，部分护栏放开（Project Glasswing 等受信场景）
- 主打：长程 Agent、自检、多天任务、自己写测试验证

**哲学演变**：

| 维度 | 早期 Claude | Fable 5 |
|------|------------|---------|
| 对齐形态 | 宪法内化 | 宪法 + **外部分类器** + 双 SKU |
| 高风险处理 | 原则性拒答 | **降级到 Opus**（更实用主义） |
| 能力叙事 | 谨慎助手 | 有原则的行动者 |
| 气质 | 康德式个人 | **康德式制度**（原则+治理） |

**配方图**：

```
康德层：宪法、HHH、安全>伦理>有用
约纳斯层：Mythos 分级放行
治理层：分类器、Fallback
杜威层：Agent、自检、验证
─────────────
地基：休谟式预训练（is）
```

**结论**：Fable **未换宗教**；从「内心原则」升级为 **「原则 + 制度」**，工程版康德 2.0。

### 2.4 哲学版康德 vs 工程版康德（本轮核心框架）

#### 哲学版康德（康德原意）

- **问题**：无上帝、无纯经验时，道德如何成立？
- **定言命令**：只按可普遍化的准则行动；人作为目的，非手段
- **自律**：理性自我立法，非服从外部偏好
- **认识论**：先天范畴整理经验（反休谟纯经验）
- **主体**：自由意志、责任、完整道德主体

#### 工程版康德（AI 对齐借用的形状）

| 工程做法 | 借用的康德概念 | 实际是什么 |
|----------|----------------|------------|
| 宪法文本 | 普遍法则 | 人写的规则清单 |
| Constitutional AI | 理性自查 | 训练出的自我批评行为 |
| 安全>有用排序 | 义务优先于欲望 | 损失函数/产品优先级 |
| 拒答/Fallback | 道德边界 | 分类器、路由策略 |

#### 根本差别

| | 哲学版 | 工程版 |
|--|--------|--------|
| 规范来源 | 理性自我立法 | 人类立法 + 训练塑造 |
| 主体 | 真道德主体 | 统计预测器模拟原则 |
| 遵守理由 | 理解「应当」 | 奖励/目标函数 |
| 责任 | 人负责 | 公司/policy 负责 |

**一句分辨**：

> 哲学版康德：规范是理性的，主体是真的。  
> 工程版康德：规范像理性的，主体是模拟的。

### 2.5 与休谟、密尔的全家桶坐标

| 传统 | 核心 | AI 对应 |
|------|------|---------|
| **休谟** | 经验、习惯、偏好 | 预训练、RLHF |
| **密尔** | 效用、后果、多目标权衡 | GRPO 奖励加权、DeepSeek |
| **康德（哲学）** | 可普遍化原则 | （模型达不到） |
| **康德（工程）** | 原则约束行为 | Constitutional AI、Claude |
| **杜威** | 知与行在情境中检验 | Agent、自检（Fable、GPT-5.5） |
| **约纳斯** | 责任前置 | Preparedness、Mythos 分级 |

**Claude** = 休谟底座 + 工程版康德外壳（+ Fable 时代加入杜威行动层、约纳斯治理层）

### 2.6 用户直觉的哲学解释

**为何体感 Claude 更靠谱**：

1. 优化目标偏 **该不该**，非 **讨不讨好**
2. 拒答/不确定更像 **负责任主体**，非硬编好看答案
3. 语气克制，触发对 **审慎理性人** 的社会信任
4. 这是 **工程版康德的产品体验**，非真道德主体

**使用时的清醒边界**：

- 工程版已足够改善日常信任感
- 不能等同于哲学版康德的真理解/真负责
- 事实类、Agent 完成类任务仍需 **三层信任** 与外部验收

## 三、延伸补充

### 思考延伸

**1. 「靠谱感」是可设计的**

用户偏好 Claude，不必假定其「更真」。工程版康德通过 **原则排序 + 诚实训练 + 边界可预期** 即可产生靠谱体感——这对 AI 伦理是好消息（对齐可工程化），也是警告（表演原则与持有原则难区分）。

**2. Fable 的 Fallback：实用主义对义务论的补充**

纯康德式应「因为不对而不做」；Fable 选择「用较弱但仍强的 Opus 应答」——在 **不彻底拒绝用户** 与 **不释放 Mythos 级危险能力** 之间折中。这是 **密尔/杜威** 对 **康德** 的补充，标志 Anthropic 从纯粹规范伦理走向 **规范 + 后果权衡** 的治理伦理。

**3. Mythos/Fable 双轨的哲学诚实**

承认「同一能力体，不同 ought 外壳」——比假装一个模型既能全网发布又能无限能力，更诚实。类似政治哲学中 **权利分级、特许执照**；危险能力不应按普通聊天产品逻辑放行。

**4. 评价任何模型的两问**

- ought 从哪来？（偏好 / 原则 / 法规）  
- 是原则内化，还是原则表演？（新场景、Agent 完成压力、越狱）

**5. 与前期笔记的系列关系**

本笔记承接：`大模型哲学流派对比` → `休谟哲学与大模型` → `is-ought-RLHF与GPT-5.5` → **本笔记（康德/Claude 系）**。  
完整坐标：休谟（地基）→ is/ought 鸿沟（裂缝）→ RLHF/宪法（填沟方式）→ 三层信任（使用标准）→ 哲学/工程康德（Claude 理论账户）。
